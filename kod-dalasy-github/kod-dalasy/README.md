# Код Даласы

Код Даласы — 7–8 сынып оқушыларына арналған тегін білім беру веб-ойыны. Оқушылар информатиканың «Алгоритм» бөлімін Python тілінде код жазу арқылы ойын түрінде меңгереді.

## Мүмкіндіктері

- 3 тарауда 14 деңгей бар: сызықтық (1–6), тармақталған (7–10) және циклдік (11–14) алгоритмдер.
- Оқушы Python тілінде код жазады, ал батыр сол командаларды картада орындайды.
- Кодтың блок-схемасы автоматты түрде сызылады.
- Бір деңгейде бірнеше карта нұсқасы бар: алгоритм барлық нұсқада жұмыс істеуі керек.
- Қыран тәлімгері дайын шешімді айтпай, кеңес береді.
- Оқушылар аты, сыныбы және PIN кодымен тіркеледі, сондықтан бір компьютерді бірнеше оқушы кезекпен қолдана алады.
- Мұғалім бетінде оқушылардың барысы, деңгейлердің шешімдері мен оқу мақсаттары (7.3.2.1, 7.3.3.2, 8.3.3.1, 8.3.3.2) бар, нәтижелерді CSV файлына жүктеуге болады.
- Ойын үш тілде жұмыс істейді: қазақ, орыс және ағылшын.

## Папка құрылымы

```
kod-dalasy/
├── index.html        басты бет
├── css/style.css     стильдер
├── js/
│   ├── i18n.js       үш тілдегі мәтіндер
│   ├── engine.js     Python интерпретаторы және деңгейлер
│   ├── flowchart.js  блок-схема
│   ├── sound.js      дыбыс (Web Audio)
│   └── app.js        интерфейс, тіркелу, мұғалім беті
├── assets/favicon.svg
└── .nojekyll
```

Ойынға сервер мен дерекқор керек емес. Деректер браузерде (localStorage) сақталады.

## GitHub-қа жүктеу және сайт ретінде ашу

1. github.com сайтында **New repository** басып, атын `kod-dalasy` деп жазыңыз. **Public** таңдап, **Create repository** басыңыз.
2. **uploading an existing file** сілтемесін басыңыз.
3. `kod-dalasy` папкасының **ішіндегі** барлық файл мен папканы сүйреп әкеліңіз: `index.html`, `README.md`, `css`, `js`, `assets`. Папканың өзін емес, ішіндегісін салыңыз, сонда `index.html` репозиторийдің түбірінде тұрады.
4. **Commit changes** басыңыз.
5. **Settings → Pages** бөлімінде **Source: Deploy from a branch**, **Branch: main**, **/(root)** таңдап, **Save** басыңыз.
6. 1–2 минуттан кейін сайт мына мекенжайда ашылады: `https://<сіздің-логин>.github.io/kod-dalasy/`

`.nojekyll` файлы жасырын, сондықтан сүйреп әкелгенде жүктелмей қалуы мүмкін. Сайт онсыз да жұмыс істейді.

## Компьютерде ашу

`index.html` файлын браузерде екі рет басып ашыңыз. Интернет болмаса, ойын жұмыс істей береді, тек әріп қаріптері қарапайым шрифтке ауысады.

## Технологиялар

HTML5, CSS3, JavaScript (Canvas, SVG, Web Audio API, localStorage), JavaScript-те жазылған Python интерпретаторы.
